# Knowledge Brain

The knowledge brain is organized by domain, but all domains belong to one connected brain.

Current domains:

- `attachment`: attachment theory, bonding patterns, anxious/avoidant/secure/disorganized dynamics.
- `relationships`: communication, conflict, repair, boundaries, dating, long-term partnership.
- `polarity`: masculine/feminine polarity, embodiment, leadership, receptivity, desire, consent-aware dynamics.
- `somatics`: meditation, nervous system regulation, vagal theory, breath, body-based practices.
- `self_improvement`: personal growth, consciousness, habits, discipline, values, purpose, shadow work, and self-awareness.

Each domain contains long-form articles. The backend reads these articles and breaks them into searchable sections.

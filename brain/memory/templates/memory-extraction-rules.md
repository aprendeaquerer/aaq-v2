# Memory Extraction Rules

Extract memory only when it is useful for future support.

Prefer saving:

- stable user facts
- repeated emotional patterns
- relationship context
- goals
- boundaries
- practices tried
- open loops Eldric should follow up on

Avoid saving:

- one-off emotional noise
- unsupported assumptions
- diagnostic labels
- highly sensitive information unless the user clearly wants it remembered

When uncertain, mark the memory as `candidate`.

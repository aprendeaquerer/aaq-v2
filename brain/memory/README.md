# User Memory Brain

The user memory brain stores personal, dynamic information about a user.

Unlike the static knowledge brain, this belongs in the database because it is private user data and must be editable, suppressible, and forgettable.

Core memory categories:

- `profile_fact`
- `relationship_context`
- `attachment_pattern`
- `emotional_trigger`
- `recurring_story`
- `goal`
- `boundary`
- `practice_tried`
- `important_event`
- `open_loop`
- `preference`
